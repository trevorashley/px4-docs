# Page table of contents

`pagetoc.js` and `pagetoc.css` are copied from
[JorelAli/mdBook-pagetoc](https://github.com/JorelAli/mdBook-pagetoc/tree/fa5c09799169ae6cab299b3eeac54083fba86a15),
commit `fa5c09799169ae6cab299b3eeac54083fba86a15`.
The upstream license is preserved in `pagetoc.LICENSE`.

`index.hbs` is the default mdBook 0.5.4 template with the upstream pagetoc
markup added inside `<main>`: a `.content-wrap` around the chapter content and
a `#sidetoc` containing `nav#pagetoc`. The navigation has an accessible label.
Using the current template preserves mdBook 0.5's resource URLs and controls;
the upstream template targets mdBook 0.4.43.

When upgrading mdBook, compare `index.hbs` with the new default template
(generated by `mdbook init --theme` in a temporary directory) and reapply the
markup above. The CSS hides the page table of contents on narrow screens and
when printing; the JavaScript removes it on pages with at most one heading.
